## About me

現在はCTOとして、主に次の領域を担っています。

- プロダクト戦略と「何をつくるか」の意思決定
- 技術選定、アーキテクチャ設計、技術基盤づくり
- プロダクトチームの組織設計と開発プロセス改善
- AI・LLMを活用した新しいプロダクト価値の探索

プロダクト開発に関わるさまざまな領域を、広く経験してきたジェネラリストタイプです。一つひとつの領域を深く究めているわけではなく、経験には濃淡があります。事業成長を最大化するために「何を、どうつくるか」という抽象度の高い問題に向き合い、広い知見を活かして前に進めていくといったことが得意かもしれません。

単にソフトウェアをつくるのではなく、お客様の業務が根本から変わるような「圧倒的な価値」を届けることを大切にしています。

- ORよりANDで考えるのが好きです。どちらかを諦める前に、トレードオフを乗り越えて両立できないかをまずは考えたいタイプです。
